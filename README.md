# 🚀 Full Tech

Este projeto faz parte do desenvolvimento prático do curso técnico de **Análise e Desenvolvimento de Sistemas (ADS)** no SENAI. O objetivo inicial é a criação de uma interface funcional e responsiva, servindo como base para futuras implementações de sistemas dinâmicos.

## 📌 Sobre o Projeto

O **Full Tech** é um projeto de estudo focado na estruturação de front-end, aplicando boas práticas de semântica e estilização. O projeto foi desenhado para ser escalável, preparando o terreno para a integração futura com lógica de back-end e banco de dados.

## 🛠️ Tecnologias Utilizadas (Até o momento)

* **HTML5:** Estruturação semântica.
* **CSS3:** Estilização e responsividade.

## 📅 Próximos Passos (Roadmap)

O projeto continuará evoluindo conforme o avanço do curso:

* [ ] Interatividade com **JavaScript**.
* [ ] Desenvolvimento do Back-end com **PHP**.
* [ ] Integração com banco de dados **MySQL**.

## 💻 Como executar o projeto localmente

1. Clone este repositório:
   > git clone https://github.com/seila78/Full_Tech.git

2. Acesse a pasta do projeto no seu computador.
3. Abra o arquivo `index.html` no seu navegador de preferência.
